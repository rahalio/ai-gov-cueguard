# Cueguard — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Frontline officer

- As an officer on a domestic-violence call, I want the location’s prior incidents and caution markers before entry, so that I do not decide in an information vacuum.
- As an officer, I want to reject a predictive cue with a reason, so that bad model output does not drive my patrol plan.

### Command staff

- As a commander, I want a single incident picture across CAD, RMS, and video alerts, so that I can allocate resources without waiting for manual fusion.
- As a commander, I want disproportionality views on stops and force, so that I can intervene before community trust collapses.

### Professional standards / early intervention

- As an early-intervention analyst, I want peer-norm outliers across complaints and use-of-force, so that we coach before a crisis.
- As a professional standards officer, I want due-process workflows when an officer is flagged, so that analytics does not become covert punishment.

### Custody and disclosure

- As a custody sergeant, I want time-limit clocks and alerts, so that we do not breach detention limits.
- As a disclosure officer, I want an evidence package export distinct from intelligence holdings, so that we meet disclosure duties without over-sharing.

### Oversight / data protection

- As a data protection officer, I want every predictive model’s purpose and legal basis on record, so that processing is defensible to regulators and courts.
- As an oversight liaison, I want read-only audit excerpts for complaint investigations, so that the public can see accountability without operational compromise.
- As an officer (exception), I want to challenge an early-intervention flag with evidence, so that erroneous fusion does not damage my career.
